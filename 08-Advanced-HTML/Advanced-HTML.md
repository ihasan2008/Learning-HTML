# Advanced HTML

Advanced HTML হলো HTML-এর এমন কিছু আধুনিক (Modern) এবং উন্নত (Advanced) Feature ও Technique, যা ব্যবহার করে আরও Professional, Responsive, Accessible এবং SEO-Friendly Website তৈরি করা যায়। Basic HTML শেখার পর এই বিষয়গুলো শেখা একজন Web Developer-এর জন্য অত্যন্ত গুরুত্বপূর্ণ।

---

## 1. Advanced HTML কী?

Advanced HTML হলো HTML-এর উন্নত বিষয়গুলোর সমষ্টি। এতে Semantic Tag, Multimedia, Graphics, Accessibility, SEO, Web API এবং অন্যান্য আধুনিক Feature সম্পর্কে শেখানো হয়।

---

## 2. Semantic HTML

Semantic HTML এমন Tag ব্যবহার করে যা Content-এর অর্থ (Meaning) স্পষ্টভাবে প্রকাশ করে। যেমন—`<header>`, `<main>`, `<section>`, `<article>` এবং `<footer>`।

---

## 3. HTML Entities

HTML Entities ব্যবহার করে বিশেষ Character ও Symbol প্রদর্শন করা হয়, যেগুলো সরাসরি HTML-এ লেখা যায় না। যেমন—`&copy;`, `&lt;`, `&gt;` এবং `&nbsp;`।

---

## 4. HTML Emojis

HTML-এ Unicode Character ব্যবহার করে বিভিন্ন Emoji প্রদর্শন করা যায়। এটি Website-কে আরও আকর্ষণীয় ও ব্যবহারকারী-বান্ধব করে।

---

## 5. HTML Character Encoding

Character Encoding Browser-কে জানায় HTML File-এর লেখা কীভাবে পড়তে হবে। বর্তমানে `UTF-8` সবচেয়ে বেশি ব্যবহৃত Character Encoding।

---

## 6. HTML Iframe

`<iframe>` Tag ব্যবহার করে একটি Web Page-এর ভিতরে অন্য Website, YouTube Video, Google Map অথবা অন্য Content Embed করা যায়।

---

## 7. HTML Canvas

`<canvas>` Element JavaScript-এর সাহায্যে বিভিন্ন Shape, Line, Text, Animation এবং Game Graphics আঁকার জন্য ব্যবহৃত হয়।

---

## 8. HTML SVG

SVG (Scalable Vector Graphics) ব্যবহার করে উচ্চ মানের (High Quality) Vector Graphics, Icon এবং Diagram তৈরি করা যায়, যা Zoom করলেও ঝাপসা হয় না।

---

## 9. HTML Drag & Drop

Drag & Drop Feature-এর মাধ্যমে ব্যবহারকারী Mouse দিয়ে Element টেনে (Drag) অন্য জায়গায় রাখতে (Drop) পারে। এটি Interactive Application তৈরিতে ব্যবহৃত হয়।

---

## 10. HTML Geolocation

Geolocation API ব্যবহার করে ব্যবহারকারীর বর্তমান অবস্থান (Location) যেমন Latitude ও Longitude জানা যায়, যদি ব্যবহারকারী অনুমতি দেয়।

---

## 11. HTML Web Storage

Web Storage ব্যবহার করে Browser-এ Data সংরক্ষণ করা যায়। এর দুটি অংশ হলো `localStorage` এবং `sessionStorage`।

---

## 12. HTML Web Workers

Web Worker ব্যবহার করে Background-এ JavaScript Code চালানো যায়, ফলে Website ধীর (Slow) হয়ে যায় না এবং User Experience উন্নত হয়।

---

## 13. HTML Accessibility

Accessibility (A11Y) এমনভাবে Website তৈরি করার পদ্ধতি, যাতে প্রতিবন্ধী (Disabled) ব্যক্তিরাও সহজে Website ব্যবহার করতে পারেন। Screen Reader, Keyboard Navigation এবং ARIA Attribute এতে গুরুত্বপূর্ণ ভূমিকা রাখে।

---

## 14. HTML SEO Basics

SEO (Search Engine Optimization) হলো Website-কে Search Engine-এর জন্য উপযোগী করার প্রক্রিয়া। সঠিক Title, Meta Tag, Heading, Semantic HTML এবং Image-এর `alt` Attribute SEO উন্নত করতে সাহায্য করে।

---

## 15. HTML Best Practices

Professional HTML Code লেখার জন্য কিছু নিয়ম অনুসরণ করা উচিত। যেমন—Semantic Tag ব্যবহার করা, Proper Indentation বজায় রাখা, Meaningful Attribute লেখা, Accessibility অনুসরণ করা এবং HTML Validation করা।

---

## 16. Common HTML Mistakes

HTML শেখার সময় কিছু সাধারণ ভুল হয়, যেমন—Tag ঠিকভাবে Nest না করা, Closing Tag ভুলে যাওয়া, `alt` Attribute না লেখা, Deprecated Tag ব্যবহার করা এবং একই `id` একাধিকবার ব্যবহার করা।

---

## 17. HTML Validation

HTML Validation-এর মাধ্যমে HTML Code Standard অনুযায়ী সঠিক কিনা তা পরীক্ষা করা হয়। Validation করলে Error কমে এবং Browser Compatibility বৃদ্ধি পায়।

---

## 18. Real Project Example

Advanced HTML ব্যবহার করে Portfolio Website, Blog Website, Business Website, E-commerce Website, Landing Page এবং Dashboard-এর মতো বাস্তব Project তৈরি করা যায়।

Advanced HTML হলো HTML-এর আধুনিক ও উন্নত অংশ, যেখানে Semantic HTML, Entity, Emoji, Character Encoding, Iframe, Canvas, SVG, Drag & Drop, Geolocation, Web Storage, Accessibility, SEO এবং অন্যান্য গুরুত্বপূর্ণ বিষয় শেখানো হয়। এগুলো শেখার মাধ্যমে আরও Professional, Modern এবং User-Friendly Website তৈরি করা সম্ভব হয়। এরপর CSS এবং JavaScript শেখার মাধ্যমে পূর্ণাঙ্গ Frontend Development শুরু করা যায়।
