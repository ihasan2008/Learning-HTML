# HTML Content

## 1. HTML Content কী?

HTML Content হলো একটি Web Page-এর ভিতরে থাকা সকল দৃশ্যমান (Visible) এবং অর্থবহ (Meaningful) তথ্য, যেমন—লেখা, ছবি, লিংক, তালিকা, টেবিল, ফর্ম, অডিও, ভিডিও ইত্যাদি, যা Browser ব্যবহারকারীর সামনে প্রদর্শন করে।

---

## 2. HTML Content Types

HTML Content বিভিন্ন ধরনের হতে পারে। প্রতিটি ধরনের Content নির্দিষ্ট উদ্দেশ্যে ব্যবহার করা হয়।

### 2.1 Text Content
- Heading
- Paragraph
- Text Formatting
- সাধারণ লেখা প্রদর্শনের জন্য ব্যবহৃত হয়।

### 2.2 Image Content
- Image
- Picture
- Figure
- Website-এ ছবি প্রদর্শনের জন্য ব্যবহৃত হয়।

### 2.3 Link Content
- Internal Link
- External Link
- Email Link
- Phone Link
- এক Page থেকে অন্য Page-এ যাওয়ার জন্য ব্যবহৃত হয়।

### 2.4 List Content
- Ordered List
- Unordered List
- Description List
- তথ্য তালিকা আকারে প্রদর্শনের জন্য ব্যবহৃত হয়।

### 2.5 Table Content
- Table
- Row
- Column
- Header
- সারণি আকারে তথ্য প্রদর্শনের জন্য ব্যবহৃত হয়।

### 2.6 Form Content
- Form
- Input
- Button
- Select
- Textarea
- ব্যবহারকারীর তথ্য সংগ্রহের জন্য ব্যবহৃত হয়।

### 2.7 Media Content (Audio / Video)
- Audio
- Video
- Source
- Track
- মাল্টিমিডিয়া প্রদর্শনের জন্য ব্যবহৃত হয়।

### 2.8 Semantic Content
- Header
- Main
- Section
- Article
- Aside
- Footer
- Content-এর অর্থ ও Structure বোঝানোর জন্য ব্যবহৃত হয়।

### 2.9 Preformatted Content
- pre
- Whitespace
- Line Break
- মূল Formatting ঠিক রেখে Content প্রদর্শনের জন্য ব্যবহৃত হয়।

### 2.10 Code Content
- code
- kbd
- samp
- var
- Programming Code প্রদর্শনের জন্য ব্যবহৃত হয়।

### 2.11 Quote Content
- blockquote
- q
- cite
- abbr
- উদ্ধৃতি ও রেফারেন্স প্রদর্শনের জন্য ব্যবহৃত হয়।

### 2.12 Inline Content
- span
- em
- strong
- mark
- small
- একই লাইনের ভিতরে ছোট Content প্রদর্শনের জন্য ব্যবহৃত হয়।

## 3. HTML Content Structure

HTML Content একটি নির্দিষ্ট Structure অনুসরণ করে।

HTML Document
│
▼
<body>
│
├── Heading
├── Paragraph
├── Image
├── List
├── Table
├── Form
├── Media
└── Footer

Content Parent ও Child Relationship অনুসরণ করে Nested Structure তৈরি করে।

---

## 4. Empty Content Elements (Void Elements)

Void Element হলো এমন HTML Element যেগুলোর কোনো Closing Tag থাকে না এবং এগুলোর ভিতরে কোনো Content লেখা যায় না।

উদাহরণ—

- `<br>`
- `<hr>`
- `<img>`
- `<input>`
- `<meta>`
- `<link>`
- `<base>`
- `<source>`
- `<track>`
- `<area>`
- `<embed>`
- `<col>`
- `<param>`

---

## 5. HTML Content Rules

HTML Content লেখার সময় কিছু নিয়ম অনুসরণ করা উচিত।

- Proper Nesting ব্যবহার করুন।
- Closing Tag সঠিকভাবে লিখুন।
- Void Element-এ Closing Tag লিখবেন না।
- সঠিক Indentation বজায় রাখুন।
- Semantic Tag ব্যবহার করুন।
- Accessibility অনুসরণ করুন।
- অর্থবহ Content লিখুন।
- HTML Validation অনুসরণ করুন।
